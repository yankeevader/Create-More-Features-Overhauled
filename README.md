**Create: More Features - Overhauled** is a maintained fork of the original **Create: More Features** mod for NeoForge 1.21.1.

This fork continues from the original `0.9.69` release and focuses on cleaning up, fixing, rebalancing, and maintaining the mod for modern packs.

Original mod:

https://www.curseforge.com/minecraft/mc-mods/create-more-features

---

# What's New in Overhauled

- Rebalanced villager trade pricing
- Restored old placeholder traders into functional professions
- Updated villager trades around modern Create content
- Improved Easy Villagers compatibility
- Rebalanced and cleaned recipe data
- Restored missing railway casing stonecutting recipes
- Removed duplicate legacy recipe namespaces
- Fixed broken or unfinished content paths
- Cleaned legacy generated code
- Modernized internal NeoForge project metadata
- Updated project identity for the Overhauled fork

---

# Installation

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.222 or newer
- Create 6.0.x

## Install

1. Install the required dependencies.
2. Place `create_mf-1.0.0-overhauled.jar` into your `mods` folder.
3. Use the same Overhauled version on both client and server.
